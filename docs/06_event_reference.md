## Normalized Event Types

The Android application uses normalized event identifiers:

* pump_suspended
* pump_resumed
* cartridge_site_change
* sensor_session_ended

These identifiers are generated by the Kotlin BFF adapter and consumed by the
UI layer. Event 9 supplies the most recent remaining-insulin and battery
values together with their pump-local event timestamp.
