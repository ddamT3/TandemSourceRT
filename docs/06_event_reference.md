## Normalized Event Types

The Android application uses normalized event identifiers:

* pump_suspended
* pump_resumed
* cartridge_site_change
* sensor_session_ended

These identifiers are generated by the decoder and consumed by the UI layer.

## Notes

Event coverage is continuously evolving as additional Tandem event types are analyzed and mapped.
